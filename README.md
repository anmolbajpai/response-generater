# 🤖 AI Response Generator — Frontend

A React-based frontend for an **AI-powered Response Generator** that helps YouTubers, influencers, and content creators generate suitable responses to comments and feedback using **Google Gemini AI**.

## ✨ Features

* 🔐 User login
* 💬 Enter comments and feedback
* 🤖 Generate AI-powered responses
* 📋 View saved responses
* ✏️ Edit responses
* 🗑️ Delete responses
* 🔄 CRUD operations
* 🔗 Integration with Spring Boot REST APIs
* 📱 Responsive and user-friendly UI

## 🛠️ Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Axios
* REST API

## 🔄 Application Flow

```text
User
 ↓
React Frontend
 ↓
Spring Boot REST API
 ↓
Gemini AI / MySQL
 ↓
Generated Response
 ↓
React UI
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/anmolbajpai/response-generater
cd response-generator-frontend
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

The frontend will start on the configured local development port.

## 🔗 Backend
